Templates, not sources. One row, one name, 44px — clicking anywhere on it copies, and the row answers with Copied. No badges, no buttons, no markdown preview: the repo name sits once in the header, and reading a template is the side panel's job. The gear in the header is the only route to configuration.
Every source gets a header rule, and every header collapses. With one repo that is a single line naming it; with several, each group folds away so you can keep only the one you're working in open — clicking a header toggles it. Because a source can be scoped to one organization, the popup only shows what is in scope for the tab you're on, so the same install can show one group on one org and two on another.
